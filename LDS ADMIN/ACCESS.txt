 STRATUS WEATHER - LIGHTNING ALERT ADMIN PANEL - ACCESS DETAILS
========================================================================

  NOTE: This is the shareable copy. Live passwords have been redacted.
  The unredacted version stays in the private working folder.

PANEL URL (HTTPS)
-----------------
  https://<your-panel-host>

  Staff sign-in:     https://<your-panel-host>/login
  Client sign-in:    https://<your-panel-host>/client
  Webhook from Pi:   https://<your-panel-host>/<client>/api/v1/lightning
  Delivery receipts: https://<your-panel-host>/api/sms/dlr


TWO FRONT DOORS
---------------
  /login   Stratus Admin. Signs in with an e-mail address and lands on the
           client list, from where any client panel can be opened or managed.

  /client  A client site. Signs in with its own short sign-in name, e.g.
           GWLD1, and lands directly in its own panel. Nothing else is
           reachable from there.

  A client's sign-in name is set by Stratus on the client list:
  Manage -> Client sign-in name. Existing panels were given their panel
  address as their sign-in name automatically.


LOGINS
------
  Both accounts are seeded on first boot from the server .env file
  (INITIAL_ADMIN_* and INITIAL_OPERATOR_*). Set those values before the
  first start, then change the passwords in-app.

  1) ADMIN  (full access: recipients, groups, events, test alerts,
             users, settings / gateway status)
       Email:     <INITIAL_ADMIN_EMAIL from .env>
       Password:  <INITIAL_ADMIN_PASSWORD from .env>

  2) OPERATOR  (site user: view alerts, add/manage recipients,
                set alert distance threshold, switch alerts on/off.
                NO access to users, settings or API/gateway secrets)
       Email:     <INITIAL_OPERATOR_EMAIL from .env>
       Password:  <INITIAL_OPERATOR_PASSWORD from .env>


NOTES
-----
  - Alerts are SMS only.
  - Alert stages: each client panel can define escalating distance bands
    (for example 30 km advisory, 20 km warning, 10 km stop work) under
    "Alert Stages". A strike raises only the nearest band that covers it,
    so one flash never sends the same person several messages. A panel
    with no stages keeps using each group's own distance threshold.
  - Change both passwords after first login: top-right "Change password".
  - Seeding is idempotent: if the database already has an account with the
    same email it is NOT overwritten, so editing the seed password later
    has no effect.
  - Set the panel hostname to match your own DNS record.
