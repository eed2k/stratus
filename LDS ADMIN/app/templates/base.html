{# Critical loader styles, inlined on purpose. The page used to show a brief unstyled flash on load. An external stylesheet cannot fix that, because the flash happens in the window before that stylesheet arrives. These few rules ship in the first packet of the document, so the overlay covers the page from the very first paint. Two safety properties, both deliberate: * The overlay is layered OVER the content. Nothing sets display:none on the page itself, so the content is always present for assistive technology and for a reader with images or scripts blocked. * The dismissal is driven by a CSS animation with a hard timeout, not only by JavaScript. If app.js fails to load or throws, the overlay still clears itself, so a script error can never leave the panel blank. #} {# Purely visual: the content underneath is never hidden, so this is kept out of the accessibility tree rather than announced as a live region. #}
