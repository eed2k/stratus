Produce a forecast

Launched from the most recent hour in the record, not from the wall clock, so uploading an older export forecasts from the end of that export.

Score against the record you already hold

Re-issues forecasts from base hours in the past, each using only the data that existed before its own base hour, then scores them against what actually happened. This is what fills the verification page immediately instead of waiting days for new observations.

Position

Needed only if you want a model background. The logger file does not carry coordinates.

Model background

Off by default. The forecast is built from this station's own history; a model background adds knowledge of weather the site has not seen before, and the station record then corrects it for the site. Choose the variables deliberately: a background helps temperature and pressure most, and can make wind worse at a sheltered site.
